# Tai Pham website

| What you want to change | File |
|---|---|
| Any text, links, email, projects, career | `content.js` |
| Profile picture | replace `images/profile.jpg` (or change `profileImage` in `content.js`) |
| Background behind the intro | replace `images/background.jpg` |
| Project screenshots | put files in `images/projects/` and set `image:` in `content.js` |
| Colours and spacing | top of `style.css` |
| Page title / search description | `<title>` and `<meta description>` in `index.html` |

Do not need to touch `script.js`.

Open `index.html` in a browser to preview. To publish on GitHub Pages, upload all files and folders as they are.
